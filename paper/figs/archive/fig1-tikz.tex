  \caption{\textbf{(a)} In a CLM, the model edits a mirror of its own transcript.
  Each turn it issues one command that can keep, shorten, offload, or delete earlier blocks; the harness reads the edited mirror back as the next prompt.
  When the context reaches the budget, the trial ends.
  \textbf{(b)} Our measurement.
  A logged trial is replayed exactly, and at each decision point ten replies are sampled from the identical prompt and executed in separate copies of the sandbox.
  Samples with the same effect on the context form one cluster; semantic entropy is computed over clusters (Experiment~2).
  A linear probe reads the same quantity from activations before generation (Experiment~3).}
